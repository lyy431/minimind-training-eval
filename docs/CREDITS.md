## Claude Code 协助的阶段

依据首次交接报告，早期工作覆盖预训练/SFT、身份LoRA、GRPO、数学工具RL、DPO、MoE、白盒与黑盒蒸馏、蒸馏后RL，以及本地网页演示、数据重建和评测辅助脚本。早期云端日志原在`out/*.log`，本仓库归档至`my_eval/logs/cloud/`。

这是工作阶段的来源说明；最初目录没有Git历史，因此不按当前文件时间或名字推断每行代码的工具作者，也不制造历史提交。

## Codex接续阶段

接续工作包含官方模型对比、身份保留补丁、同训练量继续蒸馏对照、测试同文检查、完整回答一致性判分、多候选功能、工具选择首轮失败与第二轮验收，以及普通聊天本体修复。单项报告说明了开发迭代、保留的失败记录、验收条件与局限。

当前仓库是一次有出处的完成状态快照；Git提交日期表示归档日期，不是早期实验发生日期。

## 外部模型与数据

- Qwen2.5-1.5B-Instruct用于部分黑盒蒸馏示范，教师输出需筛选，不能默认正确。
- InternLM2-1.8B奖励模型用于部分训练奖励和候选偏好评分，奖励不等于答案正确性。
- MiniMind上游数据、教师、奖励模型各自的许可证与来源要求独立适用。根目录LICENSE主要覆盖本仓库所继承与新增的代码，不作为所有外部语料和模型权重的统一许可声明。
